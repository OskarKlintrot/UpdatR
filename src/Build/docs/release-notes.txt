- Add minimum package publication age ("cooldown") support, matching NuGet's new `minPublishAgeHours` (.NET 11 SDK): `--min-publish-age-hours`, `UpdateOptions.MinPublishAgeHours` and `minPublishAgeHours` in `.updatrrc`, plus `minPublishAgeHours` on package sources and `minPublishAgeExceptions` in `nuget.config`. Versions published too recently aren't picked as update targets and are reported as skipped with the new `SkippedUpdateReason.MinimumPublishAge`.
